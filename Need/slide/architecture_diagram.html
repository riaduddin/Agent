📊 Real-Time Data Flow
1 Client connects via WebSocket with JWT token
2 Server verifies token and checks presentation status
3 Server sends status message (fresh connection - only new data)
4 Worker acquires lock in Redis for presentation processing
5 Agent starts processing in background (async)
6 Agent writes output to MongoDB + publishes to Redis Pub/Sub
7 All workers receive message from Redis and forward to connected clients
8 Client receives real-time slide generation updates
9 Agent completes, sends terminal message, releases lock
