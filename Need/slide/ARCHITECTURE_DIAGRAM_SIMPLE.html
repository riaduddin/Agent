📋 CREATE PRESENTATION REQUEST FLOW
1
Client sends request via WebSocket with query, files, JWT token
2
Authentication: Verify JWT, extract user_id, validate permissions
3
Root Agent: Topic check → Query enhancement → Intent classification → Route to pipeline
4
Research Phase: Generate keywords → Parallel web search → Extract files → Store in Qdrant
5
Planning Phase: Extract specs → Estimate vibe → Generate slide outline (JSON)
6
Generation Phase: Parallel slide generators → Query Qdrant → Generate HTML → Quality verify
7
Storage & Streaming: Save to MongoDB → Emit via Socket.IO → Real-time updates to clients
